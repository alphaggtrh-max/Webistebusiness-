# Rothmeier GmbH Website

Modern website for Rothmeier GmbH, built with Next.js 15 and React 19.

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm start
```

## Before launch
- Confirm all company/contact details and job vacancy information.
- Replace or confirm project photography and ensure usage rights.
- Review the draft privacy policy against the actual hosting provider and any third-party services.
- Configure a real contact form endpoint if a form is required; the current contact page uses a direct email link.
